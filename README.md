# Landing Page Pessoal

Projeto de landing page pessoal para portfólio, com foco em apresentação profissional, área sobre mim, hard skills, soft skills e contato.

## Estrutura

- `index.html` - página principal
- `css/style.css` - estilos customizados
- `js/main.js` - comportamento da página
- `assets/` - imagens e arquivos estáticos

## Como usar

Abra o arquivo `index.html` no navegador ou no VS Code para visualizar a página.
